# Medical Billing Management System

A Python-based Medical Billing system built to demonstrate billing workflows used in international BPO environments.

## Features
- Add patient records with ICD-10 diagnosis codes and CPT procedure codes
- View all billing records in a structured table
- Update claim status: Pending, Paid, or Rejected
- Export billing reports to formatted Excel files
- Persistent data storage using JSON

## Technologies Used
- Python 3.12
- openpyxl (Excel generation)
- JSON (data storage)

## How to Run
1. Install dependency: `pip install openpyxl`
2. Run: `python billing.py`

## Project Purpose
Built as a portfolio project for the PSDF Global Rozgar Medical Billing track.
Demonstrates understanding of medical billing workflows, data management, and Excel reporting.
